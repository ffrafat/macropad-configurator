Features
Everything the Windows app does, on any computer

      

      

        
Shortcuts & macros
Any key or combination such as Ctrl+C or Cmd+Shift+4, or a sequence of up to 18 keys with an optional delay. Record it straight from your keyboard.

        
Knobs
Separate actions for turning left, turning right and pressing each knob. Ideal for volume, scrolling, zoom or brush size.

        
Media & system keys
Volume, mute, play/pause, next and previous track, screen brightness, calculator, lock screen and browser keys.

        
Mouse actions
Left, right or middle click, scroll up or down, move the pointer or drag, optionally while holding Ctrl, Shift or Alt.

        
Three layers
Keep up to three complete setups, for example editing, video calls and gaming, and switch between them on the pad.

        
Lighting
Always-on colour, light on key press, or ripple effects on pads with RGB LEDs, set separately for each layer.

Find your pad's USB ID

          
    
            
  • Mac: Apple menu → About This Mac → More Info → System Report → USB. Look at Vendor ID and Product ID.
    • 
            
  • Windows: Device Manager → Human Interface Devices → Properties → Details → Hardware Ids (VID_1189&PID_8890).
    • 
            
  • Linux: run lsusb and look for 1189: or 514c:.
    • 
            
  • Or just click Connect above: the ID shows next to the status light.

Linux: allow your browser to reach the pad

        
Run this once, then unplug and reconnect the pad:


echo 'SUBSYSTEM=="hidraw", ATTRS{idVendor}=="1189", TAG+="uaccess"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="514c", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-macropad.rules
sudo udevadm control --reload-rules

      

    

  


  

    

      
FAQ
Questions about macro keyboard software

      

        
Is there MINI_KEYBOARD software for Mac?
The seller's MINI_KEYBOARD.exe only runs on Windows. This configurator does the same job in Chrome, Edge, Brave or Opera on macOS (Intel and Apple Silicon), as well as Windows, Linux and ChromeOS.

        
Which macro keyboards are supported?
CH57x-based macro pads with USB vendor ID 1189 or 514C and product IDs 8830–8833, 8840, 8842, 8850, 8851 and 8890. That covers the common 3-key + 1-knob, 6-key, 9-key, 12-key and 15-key pads with up to 4 knobs.

        
Do I need to install anything?
No. The page talks to the pad directly through WebHID. Nothing is downloaded, and your settings never leave your computer.

        
Does it show what my keys are currently set to?
Yes. As soon as you connect, the page reads every key and knob on all three layers from the pad and shows them on the drawing, and picks the matching layout. Reading isn't supported yet on pads with USB ID 1189:8890, so for those the drawing starts blank. Nothing is stored in the browser; use Export to keep a copy of a setup.

        
Does it work with the Bluetooth version?
Yes, but connect the pad with its USB cable while you change settings. The pad stores them in its own memory, so they keep working over Bluetooth afterwards.

        
Why doesn't it work in Safari, Firefox or on my phone?
Those browsers don't support WebHID, the technology that lets a web page talk to USB devices. Use Chrome, Edge, Brave or Opera on a computer.

        
Is this the official software?
No. It is an independent, free tool that speaks the same USB protocol as the Windows app. It is not affiliated with any macro keyboard maker or seller.
